# SentimentMapper: Mapping Sentiments Towards Disaster Response Using Social Media Data

![License](https://img.shields.io/badge/license-MIT-blue.svg)

## 📘 Overview

**SentimentMapper** is a novel framework designed to analyze and map public sentiments towards emergency needs during disasters using real-time social media data. With the increasing adoption of platforms like Twitter (now X), understanding public emotions and requirements has become essential for enhancing the effectiveness of disaster response and resource allocation.

This repository contains the published copy of the research paper:
